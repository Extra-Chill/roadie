Credential pools: API keys work for any provider (issue #136). Pool routing moved from the HTTP fetch layer to the LanguageModel level: `createRoadiePoolProvider().languageModel(rotationName)` now returns one delegating `LanguageModelV3` whose `doGenerate`/`doStream` read and strip the `x-roadie-*` call headers (comma pool list, fail-closed 401s unchanged), resolve candidates with the existing router (per-pool rotation, per-pool cooldowns, Anthropic OAuth refresh), and dispatch each candidate through **that provider's own AI SDK model** — so one rotation can mix providers (e.g. `anthropic/claude-sonnet-5-5` then `zai-coding-plan/glm-5.3-flash`) and a z.ai/Groq/OpenRouter/Google/DeepSeek key is never sent to `api.openai.com` anymore. An `APICallError` with status 429 marks the cooldown (`retry-after` when present) and tries the next candidate; any other error is returned as-is; `markUsed` runs on success. Providers resolve through a new models.dev catalog (`cli/src/credentials/provider-catalog.ts`): the data opencode already caches (`$XDG_CACHE_HOME/opencode/models.json`), else one fetch of `https://models.dev/api.json` cached under `<dataDir>/credentials/models-dev.json`; a provider maps to a bundled AI SDK package (`@ai-sdk/anthropic`, `@ai-sdk/openai`, `@ai-sdk/openai-compatible`, `@ai-sdk/google`, `@ai-sdk/groq`, `@ai-sdk/xai`, `@ai-sdk/mistral`, `@openrouter/ai-sdk-provider`), else to `@ai-sdk/openai-compatible` against the catalog's `api` URL (185+ providers), else to the account's own base URL, else unsupported with a clear error. API-key accounts gained an optional `baseURL` (stored on the account, `roadie credentials add-key --base-url`, and an optional `/credentials add-key` modal field) that wins over the catalog and covers custom/self-hosted endpoints. `/credentials add-key` no longer hardcodes `anthropic|openai`: the provider stays free text and is validated against the catalog with close-match suggestions. Anthropic OAuth keeps its adapter (the Claude Code shaping now rides a shaping fetch on `@ai-sdk/anthropic`); unknown OAuth providers stay unsupported. `roadie credentials import-subrouter` imports API-key accounts for any catalog-resolvable provider (e.g. `zai`) and only skips unsupported OAuth. Removed the two-wire routing (`wireForProvider`, `wireFromRequestUrl`, `DEFAULT_OPENAI_COMPATIBLE_BASE_URL`). The credential-pools spike adds a third OpenAI-compatible provider with its own base URL and checks requests are routed there.
