Per-person MCP servers authenticated with the person's own OAuth credential (#152). The identity hook (and `person` filter) can return `mcp_servers: [{ name, url, credential? }]` (https, or http for loopback; invalid, duplicate and denied-person entries are dropped). Each person's OAuth token is stored in Roadie's credential store at `<dataDir>/mcp-credentials/<person>/<credential>.json` (0600 files in 0700 directories, one directory per person key, never printed or logged) and refreshed under a per-record lock with the rotated refresh token persisted. Manage tokens with `roadie credentials mcp set|list|remove --person <key>` (token JSON on stdin). On a person's turn Roadie registers their servers with the OpenCode project under a person-scoped name (`roadie_pm_<hash>_<name>`) with their bearer token, and the turn's session rules reset `roadie_pm_*` to deny then allow only that person's scope; the generated OpenCode server config denies `roadie_pm_*` by default, so people without config, denied people and CLI-asserted actors see none of these tools. The shared `/mcp` command hides person-scoped servers. A speaker change inside one thread re-scopes the session to the new speaker on their turn.
