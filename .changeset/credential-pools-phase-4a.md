Credential pools phase 4a: pools are on by default, with a one-time startup migration from subrouter. Subrouter still loads in this release (removal is 4b); disable pools entirely with `--no-credential-pools` or `ROADIE_CREDENTIAL_POOLS=0` (OpenCode's own auth.json applies again), and `--credential-pools` stays accepted as a no-op. With no rotations in the shared pool the generated OpenCode config is unchanged (no `roadie` provider), so servers that never used pools see no difference. At bot startup, after the database opens, an idempotent migration imports subrouter accounts and presets into the shared pool (only when the pool has no accounts and `$SUBROUTER_HOME`/`~/.subrouter` exists; strictly read-only on subrouter files) and rewrites stored `subrouter/<preset>` model choices to `roadie/<preset>` in `global_models`, `channel_models` and `session_models` — only when the pool has a matching rotation, clearing the variant on rewritten rows, leaving every other row untouched, and logging counts (including how many choices had no mappable rotation, e.g. presets made only of unroutable providers like github-copilot, which keep working while subrouter loads). Two new host commands for the Kimaki → Roadie path: `roadie credentials import-opencode --opencode-data <dir> [--pool shared] [--dry-run]` reads OpenCode's `auth.json` plus the `<provider>-oauth-accounts.json` rotation files and imports them under the same rules as `import-subrouter` (read-only source, validate-then-write, dedupe under the pool lock, routable providers only, counts and labels never secrets), and `roadie credentials export-opencode --opencode-data <dir> [--pool shared]` writes the pool's OAuth accounts back — the first account per provider into `auth.json` (unrelated entries preserved) and all of them into the rotation files — as the rollback direction, since refresh tokens rotate on use. Footers and `/model` now resolve `roadie/<rotation>` to the session's held route (`provider/model` in parentheses) the way `subrouter/<preset>` already did; without a route the rotation name shows.
